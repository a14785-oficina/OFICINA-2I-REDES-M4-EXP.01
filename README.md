# Exercício 01

Página de apresentação de uma marca com header, navegação, secções principais e rodapé.

## Conteúdo
- Estrutura de paginação com `header`, `nav`, `main` e `footer`
- Menu de navegação simples
- Conteúdo em secções
- Lista de links relacionados

## Como visualizar
1. Abrir `index.html` no navegador.
2. Opcionalmente, usar um servidor local para evitar pequenos problemas de carregamento em certos navegadores.

## Objetivo
Praticar a organização semântica de uma página e a criação de blocos reutilizáveis.
